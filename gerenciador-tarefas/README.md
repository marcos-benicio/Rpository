# Gerenciador de Tarefas

## Sobre o projeto

O Gerenciador de Tarefas é um sistema desenvolvido
para ajudar pessoas a organizar suas atividades
diárias de maneira simples e eficiente.

A aplicação permitirá cadastrar, visualizar,
editar e excluir tarefas.

## Objetivo

Facilitar a organização pessoal e melhorar o
controle das atividades e compromissos dos usuários.

## Funcionalidades futuras

- Cadastrar tarefas.
- Listar tarefas cadastradas.
- Editar tarefas.
- Excluir tarefas.
- Marcar tarefas como concluídas.
- Definir prazos para as atividades.

## Tecnologias utilizadas

- Python
- FastAPI
- Pytest
- Ruff
